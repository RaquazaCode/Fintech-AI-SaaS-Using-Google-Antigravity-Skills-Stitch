# Finnhub API Free Tier Capabilities (2026)

## Overview of the Free Plan and Key Limits

Finnhub’s free tier provides a surprisingly robust feature set for developers prototyping financial dashboards. It offers real-time market data for major asset classes, along with a broad range of fundamental and alternative datasets – all at no cost. However, usage is capped at **60 API calls per minute** (with an additional throttle of 30 calls per second)[\[1\]](https://www.f6s.com/software/finnhub-stock-api#:~:text=,time%20updates%20%28US)[\[2\]](https://github.com/finnhubio/Finnhub-API/issues/122#:~:text=Getting%20rate%20limits%20immediately%20on,%40omlid). The free plan is intended for **personal or developmental use** (commercial use may require a paid license) and focuses on **U.S. market coverage**[\[3\]](https://www.f6s.com/software/finnhub-stock-api#:~:text=,19). Key limitations include reduced historical depth for data, U.S.-only coverage for many endpoints, and lower concurrency allowances compared to paid plans.

Despite these constraints, the free API is **generous enough for proof-of-concept applications**[\[4\]](https://robotwealth.com/finnhub-api/#:~:text=The%20free%20tier%20is%20quite,to%2050%20calls%20per%20minute). Free users can pull most types of market and company data, just with narrower scope or history. In particular, **real-time U.S. stock, forex, and crypto quotes/trades are available on the free tier**, enabling live watchlists and streaming updates without a paid subscription[\[5\]](https://analyzingalpha.com/finnhub-api-python-tutorial#:~:text=The%20free%20plan%20allows%20you,US%20stocks%2C%20forex%2C%20and%20crypto). Each API request returns JSON data, and an API key (obtained with a free Finnhub account) is required on every call (e.g. via token=YOUR\_API\_KEY query parameter)[\[6\]](https://robotwealth.com/finnhub-api/#:~:text=A%20nice%20python%20library%20for,python). There is no separate “trial” tier – the free plan **is** the entry-level plan, and it remains free indefinitely with the above rate limits (barring any future changes).

## API Access and Authentication

To use the free API, you must **register for a Finnhub API key** (no credit card required). All requests use a simple RESTful interface over HTTPS with predictable resource URLs, and you supply your API token as a query parameter or header on each request[\[6\]](https://robotwealth.com/finnhub-api/#:~:text=A%20nice%20python%20library%20for,python). There are official client libraries (Python, Javascript, etc.) that help manage requests and rate-limiting, but they ultimately require your API key as well[\[6\]](https://robotwealth.com/finnhub-api/#:~:text=A%20nice%20python%20library%20for,python). Be aware that using an invalid or “random” API key will not unlock the free tier limits – you must use a valid key tied to your account[\[2\]](https://github.com/finnhubio/Finnhub-API/issues/122#:~:text=Getting%20rate%20limits%20immediately%20on,%40omlid). The free API supports both REST requests and WebSocket connections (for streaming data) without any special authentication beyond the API key.

**Rate limits:** The free plan allows **60 requests per minute** (with up to 30 of those in a single second)[\[1\]](https://www.f6s.com/software/finnhub-stock-api#:~:text=,time%20updates%20%28US). If you exceed this, Finnhub returns HTTP 429 (Too Many Requests) errors[\[7\]](https://finnhub.io/docs/api/rate-limit#:~:text=Limits%20,30%20API%20calls%2F%20second%20limit). There is no fixed daily cap; you can continuously use 60 calls/minute as needed. Free users should design their integrations with these limits in mind – for example, spacing out non-urgent data fetches and using caching to avoid redundant calls. The free tier’s performance is generally reliable (community feedback indicates minimal downtime and consistent throughput[\[2\]](https://github.com/finnhubio/Finnhub-API/issues/122#:~:text=Getting%20rate%20limits%20immediately%20on,%40omlid)), making it suitable for light-weight dashboards.

**WebSocket streaming:** Free accounts can open WebSocket connections to Finnhub’s real-time data feed. WebSockets require the same API key (appended to the wss://ws.finnhub.io?token=... endpoint) and allow you to subscribe to live updates for up to **50 symbols concurrently on the free plan**[\[8\]](https://www.f6s.com/software/finnhub-stock-api#:~:text=,19). This is extremely useful for live stock tickers or forex/crypto price streams. The free plan supports streaming **real-time trades/quotes for U.S. stocks, forex pairs, and cryptocurrencies**[\[5\]](https://analyzingalpha.com/finnhub-api-python-tutorial#:~:text=The%20free%20plan%20allows%20you,US%20stocks%2C%20forex%2C%20and%20crypto). In practice, a developer can subscribe to e.g. MSFT, AAPL and get trade-by-trade updates or quote updates in real time. (Paid plans raise this limit to unlimited symbols per socket)[\[9\]](https://www.f6s.com/software/finnhub-stock-api#:~:text=,EPS%20Surprises%3A%2020%2B%20years). Using WebSockets for real-time data can significantly reduce the number of REST calls needed, helping stay within the 60/min quota for other data needs.

## Stock Market Data (Quotes, OHLCV, Intraday)

**Real-time Quotes:** Finnhub’s free API provides real-time quote data for U.S. stocks. A simple endpoint (e.g. /quote?symbol=AAPL) returns the latest price, high, low, open, previous close, and volume for the requested stock. Free users get **real-time prices with no 15-minute delay for U.S. markets**, which is a major benefit[\[10\]](https://wire.insiderfinance.io/the-7-best-real-time-stock-data-apis-for-investors-and-developers-in-2026-in-depth-analysis-61614dc9bf6c#:~:text=,open%20to%20paid%20plans%2C). (Finnhub likely sources this from exchanges that permit free redistribution, enabling live quotes at no charge.) Non-U.S. stock quotes are generally not available on the free plan due to coverage limits (the free plan is **U.S.-centric**[\[3\]](https://www.f6s.com/software/finnhub-stock-api#:~:text=,19)). If you request data for a foreign stock symbol, the API may either return an empty result or require an upgrade to a paid plan with global coverage.

**OHLCV Historical Data:** Free users can retrieve candlestick data (Open-High-Low-Close-Volume bars) for stocks via the /stock/candle endpoint. Multiple time resolutions are supported (e.g. 1-minute, 5-minute, 15-minute, 1-hour, daily, weekly, monthly bars) by specifying a resolution parameter. However, the amount of history you can pull per request is **capped to about 1 year’s worth of data at a time** on the free tier[\[4\]](https://robotwealth.com/finnhub-api/#:~:text=The%20free%20tier%20is%20quite,to%2050%20calls%20per%20minute). In practice, this is often implemented as a limit on the number of data points: for example, \~252 trading days (one year of daily data) or a few thousand intraday points. If you need more history, you can either specify a coarser resolution (e.g. monthly data – Finnhub allows *more* total time if the resolution is lower[\[4\]](https://robotwealth.com/finnhub-api/#:~:text=The%20free%20tier%20is%20quite,to%2050%20calls%20per%20minute)) or make multiple sequential calls with different date ranges. For instance, a free user can fetch daily OHLC for the last year in one call, then fetch an older date range in a second call to assemble 2 years of data, and so on (mindful of the rate limit). Full 30-year stock price histories are **not** directly available on free – deep history beyond a few years is reserved for premium plans[\[11\]](https://www.f6s.com/software/finnhub-stock-api#:~:text=,time%20updates).

All price data returned are **adjusted** for corporate actions. Finnhub’s documentation notes that historical prices are adjusted for splits (and indeed appear to be dividend-adjusted as well)[\[12\]](https://www.interactivebrokers.com/campus/ibkr-quant-news/exploring-the-finnhub-io-api/#:~:text=%27v%27%3A%20,57450708)[\[13\]](https://www.interactivebrokers.com/campus/ibkr-quant-news/exploring-the-finnhub-io-api/#:~:text=The%20data%20comes%20down%20as,it%E2%80%99s%20also%20adjusted%20for%20dividends), so you get continuous price series suitable for charting. The OHLCV data comes as lists of timestamps and prices/volume[\[14\]](https://www.interactivebrokers.com/campus/ibkr-quant-news/exploring-the-finnhub-io-api/#:~:text=,69858306%2C%2083322551%2C%2064120079%2C%2056007143%2C%2057450708). For example, a daily candles query might return JSON like:

{ "t": \[1675641600, 1675728000, ...\],   
  "o": \[152.57, 150.64, ...\],   
  "h": \[153.10, 155.23, ...\],   
  "l": \[150.78, 150.64, ...\],   
  "c": \[151.73, 154.65, ...\],   
  "v": \[69858306, 83322551, ...\],   
  "s": "ok" }

(where s is status)[\[15\]](https://www.interactivebrokers.com/campus/ibkr-quant-news/exploring-the-finnhub-io-api/#:~:text=display). This enables plotting candlestick charts or computing technical indicators.

**Intraday and Tick Data:** The free API can provide intraday bars (e.g. 1-minute candles) for recent periods, which is useful for plotting intra-day charts or performing short-term analysis. Real-time **trade-by-trade data (ticks)** is accessible via WebSocket streaming (as noted above), but **historical tick data** (tick-level history) is largely a premium feature. Finnhub’s top-tier plans include **30+ years of tick data** for U.S. markets[\[11\]](https://www.f6s.com/software/finnhub-stock-api#:~:text=,time%20updates), which is not feasible to obtain on the free plan. Free users can get recent intraday **minute data**, but there may be a limit on how far back intraday candles can be requested (for example, only the last few days or weeks of 1-minute data per call). For longer intraday history or full-depth tick history, an upgrade is required.

**Exchange and Symbol Listing:** Free endpoints exist to list stock symbols available. For example, stock\_symbols('US') returns a full list of ticker symbols on U.S. exchanges[\[16\]](https://analyzingalpha.com/finnhub-api-python-tutorial#:~:text=Stock%20Symbol). You must specify an exchange code (Finnhub provides a list of supported exchanges codes) to retrieve symbols for that exchange[\[17\]](https://analyzingalpha.com/finnhub-api-python-tutorial#:~:text=The%20stock_symbols,method). This can be useful for populating dropdowns or validating symbols. Since **coverage on free is U.S.-only** for stock data, requesting symbol lists for exchanges outside the U.S. may not return data (or may require a higher plan). The free tier does support a **symbol search** endpoint (symbol\_lookup) that lets you query by company name or partial ticker to find matching securities[\[18\]](https://analyzingalpha.com/finnhub-api-python-tutorial#:~:text=Symbol%20Lookup). This is handy for user-friendly lookup of ticker symbols in your app.

## Company Fundamentals and Financials

Finnhub offers a rich set of fundamental data about companies. On the free plan, you have access to many fundamental metrics for **U.S. companies**, with some restrictions on depth and detail.

* **Company Profile:** Basic company information can be fetched via the company\_profile2 endpoint (note: “Profile **v2**” is the free version)[\[3\]](https://www.f6s.com/software/finnhub-stock-api#:~:text=,19). This returns key details such as the company’s name, industry, country, market capitalization, exchange, and other descriptive info[\[19\]](https://analyzingalpha.com/finnhub-api-python-tutorial#:~:text=Company%20Profile). It’s useful for displaying company descriptions or metadata in your dashboard. The paid plans have a “Profile v1” which apparently includes more fields (possibly more comprehensive data like contact info, IPO date, etc.)[\[20\]](https://www.f6s.com/software/finnhub-stock-api#:~:text=,time%20updates), but profile v2 covers the essentials and is free.

* **Basic Financials (Key Metrics):** The company\_basic\_financials endpoint provides a grab-bag of fundamental figures and ratios for a company. By specifying the symbol and metric category (or “all”), you can retrieve dozens of metrics like P/E ratio, 52-week high/low, revenue, EBITDA, profit margins, etc. The response is structured with an outer metric object (current values for each metric) and a series object (historical time-series for certain metrics, e.g. annual or quarterly values)[\[21\]](https://www.interactivebrokers.com/campus/ibkr-quant-news/exploring-the-finnhub-io-api/#:~:text=Fundamental%20data)[\[22\]](https://www.interactivebrokers.com/campus/ibkr-quant-news/exploring-the-finnhub-io-api/#:~:text=,keys). This is **free** to use for U.S. stocks and gives a one-stop summary of a company’s fundamentals. For example, a free user can query Microsoft’s basic financials and get current ratios as well as year-by-year series for selected metrics. Keep in mind that the historical series in this endpoint might be limited (e.g. it might not go back all 30 years for every metric on the free plan). Full **“Standardized Financial Statements” (detailed income statements, balance sheets, etc. for 30+ years)** are a premium feature[\[20\]](https://www.f6s.com/software/finnhub-stock-api#:~:text=,time%20updates). In fact, Finnhub has a separate “Financials As Reported” endpoint (raw financial statements by period) which is **not available on the free tier**[\[23\]](https://robotwealth.com/finnhub-api/#:~:text=restatements,available%20on%20the%20free%20tier). So free users must rely on the summarized metrics from basic\_financials rather than full financial statement downloads.

* **Earnings Data:** Finnhub provides several earnings-related endpoints:

* **Earnings Surprises:** The company\_earnings endpoint returns recent earnings reports and the surprise (difference between actual and estimated EPS). Free users can fetch the last few quarters of earnings results. Specifically, the free plan includes **4 quarters of EPS surprise data**[\[8\]](https://www.f6s.com/software/finnhub-stock-api#:~:text=,19) – essentially the past year. In practice, you can call company\_earnings(symbol, limit=X) but Finnhub will only return up to 4 quarters for free. Paid tiers unlock decades of earnings history (20+ years on the top plan)[\[24\]](https://www.f6s.com/software/finnhub-stock-api#:~:text=,time%20updates). This data can power an “earnings surprise” component in your dashboard, showing how a company has been performing relative to expectations recently.

* **Earnings Calendar:** Finnhub’s calendar API lists upcoming (and past) earnings announcement dates. Free access is limited to **1 month of upcoming (or recent) earnings events, U.S. companies only**[\[8\]](https://www.f6s.com/software/finnhub-stock-api#:~:text=,19). This means you can get the earnings dates (and perhaps consensus estimates) for the next month’s schedule to display near-term events on a calendar widget. Real-time updates are included, so new announcements or date changes within that window are reflected[\[8\]](https://www.f6s.com/software/finnhub-stock-api#:~:text=,19). Full access (20 years worth) requires a premium plan[\[24\]](https://www.f6s.com/software/finnhub-stock-api#:~:text=,time%20updates). For a free-tier dashboard, you might show “Upcoming earnings this month” to keep within those limits.

* **Recommendation Trends:** Analyst recommendation data (the recommendation\_trends endpoint) appears to be accessible on the free plan. This provides the breakdown of analyst ratings (buy, hold, sell, etc.) for a stock and how it changes over time. The free tier should return recent data (likely the current consensus and maybe a few prior periods). This endpoint wasn’t explicitly flagged as premium in documentation, and example usage shows it working in a general context[\[25\]](https://analyzingalpha.com/finnhub-api-python-tutorial#:~:text=Recommendation%20Trends). It’s reasonable to include an “Analyst Rating” widget using this data under free limits.

* **Price Targets and Estimates:** Similarly, Finnhub has endpoints for analyst price targets and perhaps revenue/earnings forecasts. These may or may not be free – the “Stock Estimates” category includes things like price target consensus, but Finnhub’s pricing page doesn’t explicitly mention if these are restricted. Given the spirit of the free plan, basic forward-looking metrics (like the average analyst price target or next-quarter EPS estimate) could be included, but if not documented we should assume limited availability. (When in doubt, treat deep forecast data as likely premium.)

* **Corporate Actions:** Be aware that certain corporate data that was once free has moved to premium. For example, **historical dividends and stock splits data** are now premium-only endpoints (they were free initially but were reclassified around mid-2020)[\[26\]](https://github.com/finnhubio/Finnhub-API/issues/271#:~:text=It%20appears%20that%20today%20some,endpoints%20will%20become%20premium%20next). Likewise, “Major Developments” (significant corporate news/events) became premium[\[26\]](https://github.com/finnhubio/Finnhub-API/issues/271#:~:text=It%20appears%20that%20today%20some,endpoints%20will%20become%20premium%20next). So, on the free plan you **cannot** pull a full dividend history or major corporate event history for a stock. You would be limited to perhaps recent news (see News section below) or basic info like whether a stock currently pays a dividend (which might be in the profile or basic metrics).

* **Insider Transactions & Ownership:** Finnhub provides data on insider trading – i.e. officers and directors buying/selling their own company’s stock – as well as institutional shareholders. The **Insider Transactions** endpoint returns a list of insider trades over a given period. This is **free for North American companies** (only NA companies are covered)[\[27\]](https://finnhub.io/docs/api/insider-transactions#:~:text=This%20endpoint%20is%20only%20available,news). There may be a limit on how far back you can retrieve (possibly around 1 year of data, analogous to the news limit – the documentation snippet suggests free tier provides \~1 year of history)[\[27\]](https://finnhub.io/docs/api/insider-transactions#:~:text=This%20endpoint%20is%20only%20available,news). This can be used to show recent insider buying/selling trends for a stock. Similarly, **Insider Ownership** or institutional ownership data might be partly available (Finnhub has endpoints for ownership, but it’s unclear if those are free; likely they lean premium). At least insider trade lists for US stocks are available without upgrading, which is valuable alternative data.

* **IPO Calendar and Stock Fundamentals:** Finnhub also offers IPO calendars, SEC filings, and other fundamental data. These tend to be more limited on free. For example, global IPO data or a history of SEC filings would likely require premium. The free plan focuses on currently active companies rather than historical or global fundamentals.

In summary, a free-tier user can obtain **broad fundamental snapshots** for U.S. stocks (profile, key metrics, recent earnings and analyst info), but not the **full long-term financial history** or certain detailed datasets (like full financial statements or extended history of corporate actions). For a dashboard, you can still build a **fundamentals overview page** for a stock showing its valuation metrics, financial ratios, and recent performance, all with free API calls. Just keep the scope to recent data.

## Market News and Sentiment

Finnhub’s free API grants access to various news feeds and sentiment indicators that can enrich a dashboard.

* **General Market News:** The general\_news endpoint provides the latest news articles categorized by topic. You can request news for categories like "general" (market-wide news), "forex", "crypto", or "merger" news[\[28\]](https://analyzingalpha.com/finnhub-api-python-tutorial#:~:text=Market%20News). This is free and does not require a symbol. For example, you can pull general market headlines to display a news ticker or a list of top stories. The free API returns a JSON array of news items, each including headline, source, summary, URL, etc. There’s typically a limit to how many recent articles are returned per call (e.g. the last 25 or 50 articles in that category). You can call this periodically (within rate limits) to get real-time updates, as news is updated continuously.

* **Company-Specific News:** The company\_news endpoint returns news articles related to a specific stock symbol. On the free plan, this is **only available for North American companies**[\[29\]](https://analyzingalpha.com/finnhub-api-python-tutorial#:~:text=news,information%20about%20North%20American%20companies) – if you try a non-North American symbol, it will not return data (global company news requires a higher tier). Additionally, free access provides **up to 1 year of historical news for a company, plus real-time updates** for new news[\[8\]](https://www.f6s.com/software/finnhub-stock-api#:~:text=,19). That means you can query, say, Apple’s news from 2025-02-01 to 2026-02-01 and get a year’s worth of articles, and you can query recent dates to get the latest. In a dashboard, you could include a “News” section that shows recent headlines for each stock in a watchlist or on a company detail page, pulling from this endpoint. Just remember the coverage: it works great for U.S. stocks, but if your dashboard includes international equities, you won’t get news for them on the free plan.

* **Social Sentiment:** Finnhub provides **social media sentiment** data through the stock\_social\_sentiment endpoint. This endpoint aggregates sentiment from Reddit (e.g. r/WallStreetBets mentions) and Twitter for the given stock. The free tier **includes access to this social sentiment data**. The output includes lists of Reddit mentions and Twitter mentions with associated sentiment scores, ticker mention counts, and time stamps[\[30\]](https://analyzingalpha.com/finnhub-api-python-tutorial#:~:text=Social%20Sentiment). This can power a “social buzz” feature on a dashboard, indicating whether a stock is being talked about positively or negatively on social platforms. Since this is alternative data derived from public forums, Finnhub does not heavily restrict it on free accounts. It likely covers primarily U.S. tickers (as those dominate the social investment discourse), but may include some popular international ADRs if mentioned on those forums.

* **News Sentiment / Analytics:** (Finnhub may have a dedicated news sentiment or trend score, but if so, it’s likely part of premium offerings. The free plan doesn’t explicitly advertise a news sentiment score. However, one could derive sentiment by analyzing the tone of headlines from the news endpoint if needed.)

* **Real-time News via WebSocket:** Notably, Finnhub also offers a real-time news feed through WebSockets. They have mentioned a “real-time newsfeed delivered over websockets”[\[31\]](https://robotwealth.com/finnhub-api/#:~:text=One%20such%20newcomer%20is%20finnhub,time%20newsfeed%20delivered%20over%20websockets). With a free API key, you can connect to the news stream which pushes out new headlines as they cross (likely as JSON messages). This is useful if you want to display breaking news in real time without continuously polling the REST endpoint. The free tier should allow access to this feed, though it might not be well-documented in the official Python/JS clients (one may need to use a raw websocket client to subscribe). This can complement a dashboard’s news section by showing headlines the moment they’re published. Keep in mind the 50-symbol WebSocket limit[\[8\]](https://www.f6s.com/software/finnhub-stock-api#:~:text=,19) doesn’t directly apply to general news (news might be a separate channel), but if subscribing by symbol for news, you’d similarly be limited to U.S. symbols.

* **Insider Sentiment:** In addition to news, Finnhub has an **“Insider Sentiment”** indicator – essentially a measure of insider buying momentum called the **Monthly Share Purchase Ratio (MSPR)**. The stock\_insider\_sentiment endpoint returns a monthly time series of insider sentiment scores (from \-100 to 100\) for a stock[\[32\]](https://analyzingalpha.com/finnhub-api-python-tutorial#:~:text=The%20alternative%20data%20endpoint%20returns,lobbying%2C%20and%20other%20miscellaneous%20information)[\[33\]](https://analyzingalpha.com/finnhub-api-python-tutorial#:~:text=The%C2%A0stock_social_sentiment,from%20Reddit%20and%20Twitter). This data is based on insiders’ trading activity (lots of insider buying drives the score up, selling drives it down). The free tier **allows access to insider sentiment for U.S. stocks**. For example, you can get the last year of insider sentiment for MSFT or even the last 10 years, as Robot Wealth demonstrated for AAPL[\[34\]](https://robotwealth.com/finnhub-api/#:~:text=For%20now%2C%20let%E2%80%99s%20just%20grab,around%20120%20observations%20total)[\[35\]](https://robotwealth.com/finnhub-api/#:~:text=is_response%20%3D%20finnhub_client,to_date). This endpoint accepts human-readable dates for the range and returns an array of monthly sentiment records[\[36\]](https://robotwealth.com/finnhub-api/#:~:text=display%28is_response). It’s a valuable data series to include in a dashboard’s sentiment analysis section. One caveat: free data might be limited in history (Robot Wealth could pull 10 years for AAPL in early 2023[\[37\]](https://robotwealth.com/finnhub-api/#:~:text=For%20now%2C%20let%E2%80%99s%20just%20grab,around%20120%20observations%20total), implying that’s allowed – possibly because insider data doesn’t go far beyond that or Finnhub chose to give a decade). In any case, the free plan’s alternative data includes insider sentiment.

By leveraging these, a free-tier dashboard could have features like a **market news feed**, **ticker-specific news panels**, a **social sentiment widget** showing Reddit/Twitter buzz, and an **insider trading sentiment chart** – all updated within the free plan’s allowances. The main limitation is to stick to U.S. stocks for these features, due to the free coverage constraint[\[3\]](https://www.f6s.com/software/finnhub-stock-api#:~:text=,19).

## Alternative Datasets (Unique Free Data)

One of Finnhub’s differentiators is its collection of alternative data endpoints. Impressively, many of these are **accessible on the free plan**, albeit often limited to U.S. data. Here are notable alternative datasets and their free-tier status:

* **USA Government Spending (Contracts):** The stock\_usa\_spending endpoint provides data on U.S. government contracts awarded to companies[\[38\]](https://analyzingalpha.com/finnhub-api-python-tutorial#:~:text=Image). This lets you see which companies are winning federal spending dollars. For example, you can query spending data for a company like MSFT over a date range and get a list of contracts and amounts[\[39\]](https://analyzingalpha.com/finnhub-api-python-tutorial#:~:text=USA%20Spending). This is **available for free** and can be used to identify companies with large government business. It’s a unique dataset that could enhance a dashboard by showing government exposure for certain stocks.

* **Senate (and House) Lobbying:** Finnhub offers data on **lobbying activities** by companies in the U.S. Senate and House. The stock\_lobbying endpoint returns reported lobbying events involving a company, within a date range. According to Finnhub, this covers not just U.S. but also some international markets (UK, Canada, EU, etc.) for lobbying disclosures[\[40\]](https://finnhub.io/docs/api/stock-lobbying#:~:text=This%20endpoint%20covers%20US%2C%20UK%2C,). However, likely only U.S. companies’ data would be robust. The free plan is believed to include this endpoint (as it’s part of the alt data and not explicitly marked premium). It may have usage limits like “max 100 records per call”[\[40\]](https://finnhub.io/docs/api/stock-lobbying#:~:text=This%20endpoint%20covers%20US%2C%20UK%2C,), but you can page through if needed. This dataset can show how much a company spends on lobbying – an interesting insight for users.

* **COVID-19 Statistics:** As a timely dataset, Finnhub provides a covid19 endpoint which returns **real-time COVID-19 case and vaccine stats for all U.S. states**[\[41\]](https://analyzingalpha.com/finnhub-api-python-tutorial#:~:text=COVID). This is explicitly mentioned as included in the free tier[\[8\]](https://www.f6s.com/software/finnhub-stock-api#:~:text=,19). While pandemic data might be less crucial in 2026, it was a prominent addition when introduced. If relevant to your dashboard (for example, correlating consumer companies’ performance with COVID trends), this data is freely available.

* **ESG Scores and Other Themes:** Finnhub has data like ESG (environmental, social, governance) scores, investment theme classifications, and supply chain relationships. These are advanced datasets likely **not** included on free. The Finnhub pricing notes these categories as available (to attract enterprise users)[\[42\]](https://finnhub.io/pricing#:~:text=Pricing%20for%20global%20company%20fundamentals%2C,ESG%20Scores), but they are not highlighted under the free plan features. For instance, “Investment Themes” or “Supply Chain” endpoints likely require at least a paid tier.

* **Others:** Finnhub’s API includes endpoints for things like **SEC filings**, **earnings call transcripts (audio and text)**, **IPO info**, and **stock market symbol changes (ISIN to symbol, etc.)**. Most of these fall under premium access. The free plan is oriented towards data that can be aggregated from public sources. So while you might get something like **recent SEC filings headlines** free (since SEC filings are public domain), the **full text of transcripts or deep historical filing data** would require payment. If your dashboard concept relies on transcripts or filings, consider that a likely paid-only area.

Overall, free alternative data endpoints like social sentiment, insider sentiment, lobbying, and spending can add unique insights to a personal dashboard. They let you go beyond price and fundamentals into more niche analytics. Just verify each endpoint’s docs: if it’s not explicitly marked “premium only” and pertains to U.S. data, chances are you can use it with your free key. The **Robot Wealth** and **Analyzing Alpha** tutorials in 2023 made heavy use of these alt endpoints on a free key[\[43\]](https://robotwealth.com/finnhub-api/#:~:text=Alternative%20data)[\[44\]](https://analyzingalpha.com/finnhub-api-python-tutorial#:~:text=The%20alternative%20data%20endpoint%20returns,lobbying%2C%20and%20other%20miscellaneous%20information), underscoring their availability.

*(Note: Finnhub has occasionally reclassified certain alt data. For example, at one point “Major Developments” – a feed of significant company events – moved to premium[\[26\]](https://github.com/finnhubio/Finnhub-API/issues/271#:~:text=It%20appears%20that%20today%20some,endpoints%20will%20become%20premium%20next). So keep an eye on Finnhub’s announcements or pricing page for any changes in what’s free.)*

## Forex and Crypto Data

In addition to stocks, Finnhub’s free API supports foreign exchange and cryptocurrency data – a big plus for multi-asset dashboards.

* **Forex (Foreign Exchange):** You can retrieve real-time forex rates and historical forex candles on the free plan. Finnhub provides a list of supported forex brokers/exchanges via forex\_exchanges (e.g. “OANDA”, “FXCM”, “Forex.com”, etc.)[\[45\]](https://analyzingalpha.com/finnhub-api-python-tutorial#:~:text=The%20stock_symbols,method)[\[16\]](https://analyzingalpha.com/finnhub-api-python-tutorial#:~:text=Stock%20Symbol), and then you can get a list of currency pairs available on a given exchange via forex\_symbols(exchange)[\[17\]\[46\]](https://analyzingalpha.com/finnhub-api-python-tutorial#:~:text=The%20stock_symbols,method). These endpoints are free to use. Once you have a specific pair symbol (like “EUR/USD” might be denoted as EURUSD or a specific code depending on the source), you can call the same candle endpoint as stocks (or a similar /forex/candle) to get OHLC data. Free-tier forex data is typically real-time (forex markets are decentralized but Finnhub likely provides bid/ask or last price from a major source in real-time). Historical depth for forex on free is not explicitly stated, but likely similar to stocks: you can get a decent amount of history in segments, but not unlimited. Given that forex data is often easier to source, Finnhub might not heavily restrict it; still, expecting many years of minute-level FX data on free would be unrealistic. A safe bet: you can obtain recent intraday and perhaps daily history (maybe few years) for major currency pairs without paying. Forex data has global coverage by nature, and the free plan does not seem to restrict it to “US only” since currencies are international.

* **Cryptocurrency:** Crypto market data on Finnhub’s free tier is robust. The API provides crypto\_exchanges (list of supported crypto exchanges like Coinbase, Binance, etc.)[\[47\]](https://analyzingalpha.com/finnhub-api-python-tutorial#:~:text=Crypto%20Exchanges%20List) and crypto\_symbols(exchange) to list tradable crypto pairs on each exchange[\[48\]](https://analyzingalpha.com/finnhub-api-python-tutorial#:~:text=Crypto%20Symbols%20List). With a symbol (e.g. BTC-USD on Coinbase), you can fetch historical candlesticks. Crypto data from Finnhub is **real-time** and typically global, since crypto markets are open and Finnhub aggregates from major exchanges. Free users can stream crypto prices via WebSocket as well, just like stocks, which is great for building a live crypto ticker or chart. There aren’t explicit free-tier caveats on crypto in the documentation – it appears **all crypto price data is free**, aside from the universal rate limit. One could get, say, Bitcoin’s price history or current quote in USD without any special permissions. Do note that the number of crypto symbols is large; if you plan a broad crypto dashboard, you’d need to handle symbol listing and selection carefully (maybe focus on top 50 coins due to rate limits).

* **Real-time vs Historical:** Both forex and crypto offer real-time quotes/trades on free. For example, you can subscribe to a WebSocket channel for EUR/USD or BTC/USD and get live tick updates with no extra cost[\[5\]](https://analyzingalpha.com/finnhub-api-python-tutorial#:~:text=The%20free%20plan%20allows%20you,US%20stocks%2C%20forex%2C%20and%20crypto). This is valuable for building live charts or alerts. Historical OHLC retrieval is done via the REST endpoints similarly to stocks. The free plan likely allows a generous slice of historical data for these (possibly more generous than stocks, as these markets often have freely available historical data).

* **Use cases:** With free forex data, you could create a currency converter or monitor, show exchange rates on a dashboard, or plot historical FX trends (recent year) for major pairs. With crypto, you can provide real-time crypto price tracking, simple technical charts for Bitcoin/Ethereum, or even a small portfolio tracker of crypto assets – all using free Finnhub data. Keep in mind the 60 calls/min limit if you query many coins; you’d likely use streaming for real-time and only pull history on demand.

In summary, **forex and crypto data are fully accessible in real-time on the free tier**, making Finnhub a great choice for a multi-asset personal project. There are no explicit geographic restrictions on these since they are inherently global markets. Just be aware of the general call limits and potential need to restrict how many symbols you track simultaneously (50 max via WS, or fewer if using REST polling).

Finnhub includes data on indices and ETFs, but free access is quite limited in this category:

The indices\_constituents endpoint (called via indices\_const in some client libraries) is **the only free method under the "ETFs & Indices" category**[\[49\]](https://analyzingalpha.com/finnhub-api-python-tutorial#:~:text=The%20indices_const,supported%20indices%C2%A0to%20this%20method). You provide an index symbol (Finnhub supplies codes for many indices – e.g. ^GSPC for S\&P 500 or ^DJI for Dow Jones) and it returns the list of constituent ticker symbols[\[49\]](https://analyzingalpha.com/finnhub-api-python-tutorial#:~:text=The%20indices_const,supported%20indices%C2%A0to%20this%20method). This is very useful if you want to, for example, let users pick an index and see its members, or to fetch all S\&P500 symbols for further data pulls. Free users can get those lists without issue.

* **ETF Profile & Holdings:** Finnhub offers detailed data on Exchange-Traded Funds (like the fund’s profile, and the list of holdings with weights). **These endpoints are not available on the free tier.** They fall under premium data. So, you cannot retrieve an ETF’s holdings or sector breakdown without a paid plan. If your dashboard idea included analyzing ETF compositions or showing mutual fund holdings, you’d hit a wall on the free plan. However, if you just need the concept of an index’s members (e.g., “What stocks are in NASDAQ 100?”), that you can get for free as noted above.

* **Index Values:** You might wonder if you can get index price data (like the S\&P 500 index level). Finnhub doesn’t explicitly list a separate endpoint for indices prices – often indexes can be treated as symbols (e.g., using ^GSPC as a symbol in the stock candles API). It’s unclear if free plan allows that. Given “Coverage: US”[\[3\]](https://www.f6s.com/software/finnhub-stock-api#:~:text=,19), it’s possible you can query major U.S. indices (which are essentially market data from exchanges). If allowed, you could get daily bars for indices like S\&P or Dow for charting. But some indices are proprietary (S\&P data usually requires a license). Finnhub may or may not provide index levels; if they do, it might be delayed or only via paid plan. As a safe assumption: index price series beyond what’s publicly available might be restricted. (Alternatively, you could use index ETFs as proxies, which you can get free since they’re stocks – e.g., use SPY ETF price instead of S\&P500 index price.)

* **Historical Constituents:** Finnhub has a premium endpoint for **historical index membership** (when companies entered or left an index). That is not available on free. Free gives only the current constituents as of today for a given index[\[49\]](https://analyzingalpha.com/finnhub-api-python-tutorial#:~:text=The%20indices_const,supported%20indices%C2%A0to%20this%20method). Any deeper analysis like “who joined the S\&P this year” would require upgrading.

In short, the free tier covers **current index/ETF constituents lists** but not the rich data about indices/ETFs themselves. Use this to enhance screeners or watchlists (e.g., allow filtering stocks by index membership), but expect to use paid data for any serious ETF analytics.

## Free vs Paid – Summary of Key Differences

To maximize the free tier, it’s useful to know exactly what you **don’t get** without upgrading:

* **Global Coverage:** The free plan is U.S.-centric. You get U.S. stocks (and possibly some Canada if North America is included in certain endpoints), but you *do not get international stock data*. Paid plans unlock global markets[\[51\]](https://www.f6s.com/software/finnhub-stock-api#:~:text=,EPS%20Surprises%3A%2020%2B%20years). For instance, free users can’t fetch data for European or Asian stock tickers – those calls will fail or return nothing. Similarly, company fundamentals and news are largely only for U.S. companies on free[\[29\]](https://analyzingalpha.com/finnhub-api-python-tutorial#:~:text=news,information%20about%20North%20American%20companies). If your dashboard is meant for U.S. markets, this is fine; if you need global stocks, you’d need to upgrade to a plan with “Coverage: Global”[\[51\]](https://www.f6s.com/software/finnhub-stock-api#:~:text=,EPS%20Surprises%3A%2020%2B%20years).

* **Historical Depth:** The amount of historical data is truncated on free. As noted:

* Stock prices: effectively \~1 year per API call (though you can manually concatenate more, it’s not unlimited)[\[4\]](https://robotwealth.com/finnhub-api/#:~:text=The%20free%20tier%20is%20quite,to%2050%20calls%20per%20minute). Paid plans explicitly offer 30+ years of U.S. stock history and even tick-level archives[\[52\]](https://www.f6s.com/software/finnhub-stock-api#:~:text=,BTDS%20%26%20144A).

* Company financials: free gives current metrics and maybe some recent historical series, but *not* decades of financial statements. Paid gives 30+ years of financial statements[\[20\]](https://www.f6s.com/software/finnhub-stock-api#:~:text=,time%20updates).

* News: free \= 1 year back for company news[\[8\]](https://www.f6s.com/software/finnhub-stock-api#:~:text=,19); paid \= 20+ years archive[\[11\]](https://www.f6s.com/software/finnhub-stock-api#:~:text=,time%20updates).

* Earnings surprises: free \= last 4 quarters[\[8\]](https://www.f6s.com/software/finnhub-stock-api#:~:text=,19); paid \= 20 years[\[24\]](https://www.f6s.com/software/finnhub-stock-api#:~:text=,time%20updates).

* Earnings calendar: free \= 1 month forward[\[53\]](https://www.f6s.com/software/finnhub-stock-api#:~:text=,19); paid \= 20 years back and forth[\[24\]](https://www.f6s.com/software/finnhub-stock-api#:~:text=,time%20updates).

* Alternative data: free provides current/recent data (e.g. latest insider sentiment, recent lobbying, etc.), but if an alt dataset has a long history, some history might be truncated. (For example, if Finnhub has historical social sentiment trends, free likely gives recent months whereas paid could give more – though specifics aren’t published.)

* **Data Granularity:** Free users have access to **daily and intraday data**, but not the most granular historical data:

* **Real-time trades:** Free can stream real-time trades for U.S. stocks/forex/crypto[\[5\]](https://analyzingalpha.com/finnhub-api-python-tutorial#:~:text=The%20free%20plan%20allows%20you,US%20stocks%2C%20forex%2C%20and%20crypto). That’s as granular as it gets in real-time (tick by tick). However, if you want to *retrieve* historical trades or very fine intervals far back, that’s not available.

* **Technical indicators:** Finnhub provides a technical analysis API. On free, you can use the technical\_indicator endpoint to calculate indicators (like SMA, RSI, etc.) on a given stock’s price series[\[54\]](https://analyzingalpha.com/finnhub-api-python-tutorial#:~:text=The%20technical_indicator,various%20technical%20indicators%C2%A0for%20a%20stock). That function is notably the **only free technical analysis function**[\[54\]](https://analyzingalpha.com/finnhub-api-python-tutorial#:~:text=The%20technical_indicator,various%20technical%20indicators%C2%A0for%20a%20stock) – other specialized TA features (pattern recognition, support/resistance levels, etc.) are premium only. So, you can compute indicators by providing price data and indicator parameters (as shown in examples for SMA) on free[\[55\]](https://analyzingalpha.com/finnhub-api-python-tutorial#:~:text=The%20technical_indicator,various%20technical%20indicators%C2%A0for%20a%20stock)[\[56\]](https://analyzingalpha.com/finnhub-api-python-tutorial#:~:text=indicator_fields%20%3D%20%7B), but any fancy automated pattern detection might require paid access.

* **Multi-symbol queries:** The free API generally expects one symbol per request. There is no bulk endpoint to get, say, quotes for 50 symbols in one call (you’d have to do 50 calls or use websockets). This is not a paid vs free difference per se (even paid uses mostly one-symbol calls, aside from batch downloads in some cases). But it means on free, hitting 60 symbols would max out your per-minute quota unless you use streaming. Designing around this (e.g. limit your watchlist size or rotate through symbols) is important.

* **WebSocket Connections:** Free allows 50 symbols streaming at once[\[8\]](https://www.f6s.com/software/finnhub-stock-api#:~:text=,19); paid allows more (unlimited on the $3000/mo plan)[\[24\]](https://www.f6s.com/software/finnhub-stock-api#:~:text=,time%20updates). Also, paid users might get faster throughput or more connections, but in practice a single connection with 50 symbols is plenty for personal use. The data content streamed is the same for free vs paid; just the subscription count differs.

* **Premium-Only Endpoints:** Certain endpoints are completely unavailable to free users. Based on Finnhub’s docs and updates:

* **Dividends & Splits** – historical dividend payouts and stock split history (premium only now)[\[26\]](https://github.com/finnhubio/Finnhub-API/issues/271#:~:text=It%20appears%20that%20today%20some,endpoints%20will%20become%20premium%20next).

* **Major Developments** – a feed of major company events (premium)[\[26\]](https://github.com/finnhubio/Finnhub-API/issues/271#:~:text=It%20appears%20that%20today%20some,endpoints%20will%20become%20premium%20next).

* **Financials As Reported** – full raw financial statements (premium)[\[23\]](https://robotwealth.com/finnhub-api/#:~:text=restatements,available%20on%20the%20free%20tier).

* **IPO Calendar (global)** – likely premium.

* **Analyst Estimates (detailed)** – e.g. annual financial forecasts, possibly premium.

* **Transcripts & Filings** – raw text or audio of earnings calls or PDFs of filings, likely premium due to licensing.

* **Mutual Funds & Bonds** – *no free methods at all* in these categories[\[57\]](https://analyzingalpha.com/finnhub-api-python-tutorial#:~:text=endpoints%20have%20no%20free%20methods). Finnhub has endpoints for mutual fund info and bond market data, but those are disabled for free users[\[58\]](https://analyzingalpha.com/finnhub-api-python-tutorial#:~:text=Mutual%20Funds%20and%20Bonds).

* **International market data** (stocks, economy, etc.) – premium.

* **Advanced metrics** (like aggregated ESG scores, supply chain mapping, etc.) – premium.

In essence, the free tier offers **breadth of data with shallow depth**, whereas paid plans offer full depth and global breadth. The free plan is ideal for a U.S.-focused app that needs up-to-date data and basic history, but it won’t satisfy use cases needing comprehensive historical analysis or international coverage.

Even with the limitations, you can build a feature-rich financial dashboard on Finnhub’s free API. Here are some concrete use cases and how they fit within free-tier capabilities:

* **Real-Time Stock Watchlist:** Using the WebSocket API, you can display live price quotes for up to 50 U.S. stocks in a watchlist panel[\[8\]](https://www.f6s.com/software/finnhub-stock-api#:~:text=,19). The free tier provides real-time trade updates for these symbols[\[5\]](https://analyzingalpha.com/finnhub-api-python-tutorial#:~:text=The%20free%20plan%20allows%20you,US%20stocks%2C%20forex%2C%20and%20crypto), so you can show flashing price changes, percent change, and volume in real time. With 60 calls/min, you could also periodically refresh a few fields (like daily high/low) via REST if needed, but most data (last price, bid/ask) can come via streaming. This is fully achievable on free and would be indistinguishable from a paid setup for up to 50 symbols.

* **Stock Detail Pages with Fundamentals:** For each stock, you can create a detailed view showing the company’s profile (name, industry, description), key financial metrics (from basic\_financials – e.g. P/E, dividend yield, profit margins), and recent performance. All these fundamentals are accessible free[\[21\]](https://www.interactivebrokers.com/campus/ibkr-quant-news/exploring-the-finnhub-io-api/#:~:text=Fundamental%20data)[\[22\]](https://www.interactivebrokers.com/campus/ibkr-quant-news/exploring-the-finnhub-io-api/#:~:text=,keys). This essentially creates a mini Yahoo Finance page powered by free API calls. The main consideration is to throttle the requests – e.g. if a user views 10 different stock pages in rapid succession, that’s a lot of API calls. * **Market News Feed:** A section of the dashboard can show the latest market news (general news or category-specific). Using one API call to general\_news('general') you can fetch, say, 20 latest headlines[\[59\]](https://analyzingalpha.com/finnhub-api-python-tutorial#:~:text=Market%20News). Sector-specific news (forex, crypto, merger news) can be rotated or selected by the user, each easily fetched within free limits.

For earnings: fetch the next 4 weeks of earnings dates (the free earnings calendar covers 1 month ahead[\[53\]](https://www.f6s.com/software/finnhub-stock-api#:~:text=,19)). Display those dates and companies reporting on each date. This helps users track what’s coming. If you want economic events, you might have to manually incorporate some via external free sources, since Finnhub’s econ calendar is likely premium. However, you could show a small selection of major events manually (or omit macro events to stay within Finnhub free).

* **Portfolio Tracker:** A personal portfolio tracker feature could let a user input some holdings (e.g. 5 stocks). The dashboard then uses Finnhub free API to get current prices (via WebSocket or periodic quote calls) and maybe one-year charts for each, and calculates portfolio value in real-time. Since free tier is real-time for U.S. stocks, the portfolio value can update live. You can also use basic financials to show a snapshot of each holding’s fundamentals (PE, etc.). * **Technical Analysis Charts:** Thanks to the technical\_indicator endpoint (free for various indicators)[\[54\]](https://analyzingalpha.com/finnhub-api-python-tutorial#:~:text=The%20technical_indicator,various%20technical%20indicators%C2%A0for%20a%20stock), you can add technical studies to your charts without writing the calculations from scratch. The free plan’s 60/min rate means you can’t retrieve hundreds of stocks instantly, but with creative caching or user-driven queries, you can present quite a bit of data.

* **Alerts and Notifications:** While Finnhub free doesn’t have a push notification service, you can build an alert system by leveraging websockets and some logic. These examples show that a wide range of features – from live quotes and charts to fundamental snapshots, news feeds, and even some advanced analytics – are achievable on Finnhub’s free tier. The keys are to **stay within U.S. markets, design around the 60 calls/min constraint, and cache aggressively** where possible.

## Integration Best Practices for Free Tier Users

To maximize functionality under the free plan, consider the following strategies when integrating Finnhub into your application:

* **Leverage WebSockets for live data:** As emphasized, use the WebSocket API for any data that needs frequent updates (e.g. live prices, streaming news). This prevents you from consuming multiple REST calls per minute for each quote update. One socket connection giving live updates for 50 symbols is far more efficient than polling 50 symbols via REST every few seconds. For example, a live watchlist or portfolio value can update continuously via one connection, leaving your REST call budget free for other data.

* **Cache and reuse data:** Many data points don’t change often (or at all) daily – company profiles, fundamental metrics, index constituents, etc. Implement a caching layer or store results in memory/database so that if the same request is needed again, you don’t call the API repeatedly. For instance, cache company profiles on first request, and refresh them maybe once a day. Financial metrics might be updated quarterly, so daily caching is fine. News can be cached for at least the day, etc. By caching, you effectively multiply how many distinct data points you can show without exceeding rate limits.

* **Batch sequential calls during off-peak:** If you need to load a lot of data (say metrics for 100 companies for a screener or historical prices for 50 stocks), don’t try to fetch everything at once. Use a background task to fetch data in chunks (e.g. 5 per minute) and store it, perhaps during off hours or gradually when the app starts up. Since free tier is 60/min, you could theoretically get 3,600 data points in an hour. Plan these bulk operations when users are not actively waiting, or progressively load data and show partial results. Also respect the 30 calls/second burst limit – space out requests (the official guidance is that if you go above 30 calls in a single second, you’ll get rate-limited[\[7\]](https://finnhub.io/docs/api/rate-limit#:~:text=Limits%20,30%20API%20calls%2F%20second%20limit), even if still under 60 that minute).

* **Use lower resolution or limited ranges when possible:** To stay within data caps (like the 1-year per call for history), request only what you need. If showing a 3-month price chart, don’t fetch 5 years of data. If you only need the latest value (quote), use the /quote endpoint instead of pulling a full daily candle. The free plan encourages being specific – smaller queries are more likely to succeed and be quick.

* **Monitor API usage and fall back gracefully:** Implement logging for how many calls your application is making. If you approach the 60/min limit, be prepared to throttle or delay further requests. If a 429 response occurs, handle it by backing off. It’s good to build in a small buffer (e.g. aim for max 50 calls/min to be safe). Also, if some data is not available due to free plan (e.g. a user searches an international stock), handle that with a message like “Data not available – upgrade required” or similar, rather than letting it error out.

* **Focus on core features within constraints:** Given the free plan’s personal-use intent, tailor your integration to the most valuable features that fit in the limits. It might be better to have an app that does a few things well (e.g. tracks 20 stocks with live data, and provides fundamentals and news for those) rather than trying to cover every stock and every data point but hitting walls. Use Finnhub’s free data as the backbone for your MVP, and you can always decide to integrate more (or consider a paid plan) if the project grows.

By architecting with these patterns – **websocket streaming, caching, rate-limit awareness, and prioritizing essential calls** – you can build a smooth experience that feels real-time and comprehensive, all on the free tier.
